# MASConectados — Plataforma integral de servicios para mascotas

Actúa como un equipo senior de Product Design, UX/UI y desarrollo Full Stack.

Construye MASConectados, una plataforma digital profesional que conecta propietarios de mascotas con veterinarios, cuidadores, paseadores, tiendas, fundaciones y servicios especializados.

No crear una landing page genérica. Construir una aplicación web modular, responsive, escalable y preparada para integrar inteligencia artificial.

## 1. IDENTIDAD DE MARCA

Nombre: MASConectados.

Eslogan: Conectamos vidas, creamos bienestar.

Personalidad: amigable, confiable, innovadora, cálida y profesional.

### Logotipo

Utilizar el nuevo concepto de logo aprobado:
- Símbolo M orgánico y fluido.
- Huella blanca integrada en el interior.
- Degradado naranja vibrante.
- Wordmark MASConectados.
- MAS en carbón y Conectados en naranja.

Si se proporciona el archivo gráfico del logo, utilizarlo como recurso principal y no redibujarlo. Preparar versiones horizontal, compacta e isotipo.

No sustituir el logo por una huella genérica.

## 2. SISTEMA VISUAL

Paleta oficial:

- Primary: #FF570A
- Secondary: #FF7900
- Accent: #FF9B45
- Peach: #FFC078
- Light Peach: #FFE5CC
- Background: #FFF8F1
- Text: #33251F
- White: #FFFFFF

Distribución visual:
- 55% fondos crema.
- 25% superficies blancas.
- 12% textos y elementos carbón.
- 8% naranja vibrante.

El naranja debe destacar en botones, enlaces activos, iconos y elementos importantes, no cubrir toda la página.

Tipografías:
- Manrope ExtraBold para encabezados.
- Manrope Bold para títulos.
- DM Sans Regular para contenido.
- DM Sans Medium para navegación y controles.

Estética:
Minimalista, premium, cálida, dinámica y amigable.

Utilizar formas orgánicas fluidas, fotografías editoriales de mascotas, tarjetas redondeadas, sombras suaves y espacios amplios.

Evitar diseños infantiles, exceso de naranja, tonos marrones rojizos, verdes y componentes visualmente sobrecargados.

## 4. PÁGINA DE INICIO

Diseñar una homepage visualmente atractiva con:

- Hero principal con fotografía de perros y gatos.
- Título: "Todo lo que tu mascota necesita, en un solo lugar".
- Subtítulo: "Encuentra profesionales, servicios y productos para darle a tu mascota el cuidado que merece".
- Buscador con ubicación, categoría y fecha.
- Categorías de servicios.
- Cuidadores destacados.
- Clínicas veterinarias.
- Productos populares.
- Mascotas en adopción.
- Presentación del asistente IA.
- Testimonios.
- Footer completo.

Utilizar Medellín y el Valle de Aburrá como ubicación inicial de demostración.

## 5. MARKETPLACE DE SERVICIOS

Crear un catálogo con filtros por:
- Categoría.
- Ubicación.
- Precio.
- Calificación.
- Disponibilidad.
- Tipo de mascota.

Servicios:
- Veterinaria.
- Paseadores.
- Cuidadores.
- Hospedaje.
- Guardería.
- Peluquería.
- Entrenamiento.

Cada servicio tendrá una ficha detallada con fotografías, descripción, tarifas, disponibilidad, reseñas y solicitud de reserva.

## 6. CUIDADORES

Permitir que las personas se registren como cuidadores y publiquen sus servicios.

Crear perfiles con:
- Fotografía.
- Nombre.
- Presentación.
- Experiencia.
- Ubicación.
- Servicios ofrecidos.
- Tarifas en COP.
- Disponibilidad.
- Certificaciones.
- Calificaciones.
- Estado de verificación.

Permitir enviar solicitudes de reserva y gestionar su estado.

## 7. VETERINARIOS

Crear directorio de profesionales y clínicas.

Incluir especialidades, ubicación, horarios, tarifas, servicios y sistema de solicitud de citas.

Distinguir claramente los profesionales verificados.

## 8. MARKETPLACE DE PRODUCTOS

Crear tienda digital con:
- Alimentos.
- Juguetes.
- Accesorios.
- Camas.
- Higiene.
- Snacks.

Incluir búsqueda, filtros, ficha de producto, favoritos, carrito, resumen de compra e historial de pedidos.

Preparar la arquitectura para integrar posteriormente una pasarela de pagos colombiana.

## 9. ADOPCIONES

Crear un módulo para fundaciones y refugios.

Permitir publicar mascotas con fotografías, edad, especie, sexo, ubicación, descripción, información sanitaria y requisitos de adopción.

Incluir filtros y formularios de postulación.

## 10. ASISTENTE DE INTELIGENCIA ARTIFICIAL

Crear un asistente conversacional que ayude a los usuarios con:
- Orientación general sobre cuidado animal.
- Alimentación.
- Comportamiento.
- Recomendaciones de servicios.
- Búsqueda de cuidadores.
- Sugerencias de productos.

No emitir diagnósticos ni prescribir medicamentos. Recomendar atención veterinaria ante síntomas preocupantes.

Preparar la integración con una API de IA mediante backend seguro.

## 11. PERFIL DE MASCOTAS

Permitir registrar varias mascotas por usuario.

Campos:
- Nombre.
- Fotografía.
- Especie.
- Raza.
- Edad.
- Sexo.
- Peso.
- Alimentación.
- Alergias.
- Vacunas.
- Historial veterinario.

Incluir calendario de citas y recordatorios.

## 12. USUARIOS Y ROLES

Preparar los siguientes roles:

- Propietario.
- Cuidador.
- Veterinario.
- Vendedor.
- Fundación.
- Administrador.

Cada rol debe tener permisos y panel de gestión adecuados.

## 13. TECNOLOGÍA

Utilizar:
- React.
- TypeScript.
- Tailwind CSS.
- Componentes reutilizables.
- Supabase para autenticación y PostgreSQL.
- Supabase Storage para imágenes.
- Row Level Security para proteger información.

Mantener una arquitectura modular y separar componentes, servicios y lógica de negocio.

## 14. REQUISITOS DE CALIDAD

- Diseño responsive.
- Navegación funcional.
- Formularios validados.
- Estados de carga y error.
- Mensajes de confirmación.
- Componentes reutilizables.
- Accesibilidad básica.
- Seguridad de datos.
- Código organizado.

No crear botones decorativos sin acción.
No simular pagos reales.
No presentar datos ficticios como información verificada.
No exponer claves API en el frontend.
